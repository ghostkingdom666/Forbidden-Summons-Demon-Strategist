# 玩家入门

## 目标

士气从100开始。魔物打中勇者，勇者士气下降；勇者击杀魔物，士气上升。士气归零时获胜，到200时失败。

## 召唤与集结

点击卡牌，再点击高亮的合法外围区域。灯笼及其头领限上下区域，石头人及其头领限左右区域。

普通单位首次召唤后，1.2真实秒内继续点击合法位置可以开启集结。集结整轮费用包含首只，后续尝试有失败风险；成功单位先待命，本轮结束后一起出发。右键或Esc可结束本轮。

## 魔物分工

| 魔物 | 用途 |
|---|---|
| 幽魂 | 廉价炮灰，真实阵亡推进头领解锁 |
| 狼魂 | 高速突击，成功命中后消散 |
| 狼魂头领 | 较厚血的冲锋单位 |
| 宝箱怪 | 绕行诱敌，阵亡金币吸引勇者停下拾取 |
| 幽火灯笼 | 远程输出，幽火也能消耗骑士旋转剑 |
| 气（水）球 | 预警自爆、减速和墨渍，可以扑灭火环 |
| 石头人 | 承伤与范围砸地，可直接打断吟唱 |
| 镜贝 | 战术兵种，用于镜像与反射类战术 |
| 荆棘草 | 战术兵种，用于荆棘类战场控制 |
| 藏墨蟾 | 战术兵种，用于墨渍类战场控制 |

镜贝、荆棘草、藏墨蟾为 v0.3.0 新增的三种战术兵种，详细机制与数值可在游戏内图鉴查看。

宝箱金币只有在勇者**停下拾取时**才会被受击打断：当前金币消失，勇者1游戏秒内不再被金币吸引；走向金币时受击不会脱控。

## 四种新头领

与普通单位分开召唤，共用幽魂真实阵亡10只的解锁进度。每种最多一只、免费、不集结，各有20游戏秒召唤冷却，可以并存。

- **宝箱怪头领**：阵亡掉三个独立金币堆。
- **幽火灯笼头领**：强化远程输出，加快附近普通灯笼的攻击。
- **气（水）球头领**：首爆后，原地再发生一次延迟爆炸。
- **石头人头领**：周期补充岩甲，继续承担前排和吟唱打断。

第一章没有石头人及其头领。肉鸽中，获得普通兵种后会自动提供对应新头领卡，仍须满足幽魂阵亡条件。新头领卡面暂用空白卡加文字，详细数值可在菜单图鉴中查看。

## 主题试炼与通关记录

v0.3.0 新增主题试炼模式，并会自动记录通关情况，可回看自己的通关表现。

三种主题试炼的残页奖励与经典一致：节点15张，击败奖励3／4／5／6，通关额外3张，整局共33张；经典三战仍为24张。

## 剑与枪火增援试炼（v0.3.1）

试炼第五页新增「剑与枪火」：固定的骑士与游侠并肩作战，分两个阶段进行。两人各自拥有独立士气、成长、控制与命中去重；骑士首次被击退后整备退款，阶段奖励共24，研悟仅一次，最佳纪录只记终局。

- 恢复：无距离限制，受击后有6游戏秒宽限，1秒起手，每秒恢复3点至100；可被打断，恢复债额不会重复获得经验。
- 满条技能：誓约重斩、掩护齐射，1.5秒内主动错峰。
- 士气条：沿用原版纸面与棋子推动，双击棋子或本体可集火；35号录音同步原游侠开战对撞与落位，支持暂停和同时跳过。
- 未受击宽限由6改10游戏秒，骑士全模式基础移速由150改140。

## 研修与封存名录（v0.3.1）

- 新增三级**活墨循环**：自然资源回复 +20%／40%／60%。
- 新增三级**开局兵种家族封存**：可封存 1／2／3 个名额，让开局与后续抽选过滤掉指定兵种家族。
- 研修目录扩为九项，总价216残页；已有七项顺序与价格不变。本局内换Boss与重开保留，开新局名单为空。

## 正反馈与结算回放（v0.3.2）

- **操作拍击**：有效反射命中、石头人成功打断、达到特写重击门槛的实际伤害、本局首次头领解锁，分别以纸片拍击显示「反射命中」「施法打断」「强力命中」「头领解锁」；成功至少6只的集结批次在结束后显示「集结出战 ×N」。同帧按头领、打断、反射、集结、重击的顺序取一类，8游戏秒冷却；格挡、闪避、零伤害不出反馈，也不改变战斗数值。
- **节点标记**：士气 75／50／25 处显示小号 token，首次跨过时点亮，回升再降不重复；双勇者各自独立显示。
- **结算回放**：结算改为逐位勇者的卷轴回放，士气条从 100 回推到本局最低值，实际击败后破条再切下一位，节点与击败奖励按实际收据飞入下方残页条，完整四战约 20 秒。演出中单击鼠标或按空格可直接跳到最终值。
- **存档**：正反馈进度保存在独立存档中，不覆盖卡组、研修和历史计时；教程、练习及开过调试面板的对局不记录。

## 建议体验顺序

先从第一章理解士气与集结，再尝试游侠、法师，最后挑战肉鸽连战。失败后可以换一种组合，不必依靠重复堆同一种魔物。

暂停菜单可调整音量和显示设置。遇到不理解、看不清或觉得不公平的地方，都欢迎通过 [反馈入口](../SUPPORT.md)告诉我们。
